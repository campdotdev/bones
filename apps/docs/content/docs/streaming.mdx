---
title: Streaming
description: Bones works with whatever streams your HTML.
---

A streamed page shows skeletons on first paint. The shell renders each slow region with `aria-busy="true"`, and whatever fills the region later removes it. The stylesheet needs nothing else, so any streaming mechanism works unchanged.

## With a framework

React and Next.js: the Suspense fallback is the component with `aria-busy="true"` and no data, and React's streaming renderer swaps the content in. See [Getting started](/getting-started).

Astro server islands, Turbo Streams, and htmx each render a placeholder and replace it later. Put `aria-busy="true"` and `inert` on the placeholder.

## Without a framework

Browsers render streamed HTML in order. To fill a region near the top of the page with content that arrives later, send the content inside a `<template>` and a one-line script moves it into place. That is the whole mechanism.

**The shell.** The head, the body up to and including every slow region, and the swap function. Do not close `body` or `html`; both closing tags are optional, and later chunks parse inside the still-open body.

{/* prettier-ignore */}
```html
<!doctype html>
<html lang="en">
<head>
  <link rel="stylesheet" href="/bones.css" />
</head>
<body>
  <h1>Dashboard</h1>
  <section aria-busy="true" inert data-slot="stats">
    <h2>This week</h2>
    <p>Deploy counts and commit totals load here.</p>
  </section>
  <script nonce="…">
    function swap(id) {
      var t = document.querySelector('template[data-chunk="' + id + '"]');
      var b = document.querySelector('[data-slot="' + id + '"]');
      if (!b) { if (t) t.remove(); return; }
      if (t) { b.replaceChildren(t.content); t.remove(); }
      b.removeAttribute("aria-busy");
      b.removeAttribute("inert");
    }
  </script>
```

**A chunk.** Flush the template and the call together, template first. The script runs when its closing tag parses, so the template is complete by then even if the network splits the chunk.

{/* prettier-ignore */}
```html
<template data-chunk="stats"><h2>This week</h2><p>12 deploys, 3 rollbacks, 41 commits.</p></template>
<script nonce="…">swap("stats")</script>
```

**A failure.** Call `swap` with no template and the region keeps its placeholder children; add a marker if you want to style it:

{/* prettier-ignore */}
```html
<script nonce="…">document.querySelector('[data-slot="stats"]').dataset.error = ""; swap("stats")</script>
```

**Notes.**

- Chunk content must be balanced HTML. A stray `</template>` ends the chunk early. Nothing here escapes content; the server does.
- Put your CSP nonce on every script tag, the swap function included.
- Send `Content-Type: text/html; charset=utf-8`, and defeat proxy buffering where it applies (`X-Accel-Buffering: no` for nginx). Compression that buffers the whole response also defeats streaming.
- After the last chunk, close the connection. Nothing else is sent.
- `data-slot` and `data-chunk` are your page's names. Bones reads neither.
