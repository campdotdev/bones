## Install

```bash
npm install @camp.dev/bones
```

## Import the stylesheet

Import it once in your root layout or entry point:

```tsx
import "@camp.dev/bones/css";
```

## Mark a region busy

Set `aria-busy="true"` on the element that is loading. Every leaf under it becomes a bar and every image becomes a box. Remove the attribute when the data lands.

```html
<section aria-busy="true">
  <img src="/avatar.png" width="64" height="64" alt="" />
  <h2>Sasha Greenfield</h2>
  <p>Collects tape loops, birdsong, and the hum of old refrigerators.</p>
</section>
```

## Render a component with no data

In a framework, write the component so it renders its shell when the data is missing, and forward the rest of its props to the root element. Then the skeleton is the component with `aria-busy` and nothing else.

```tsx
import type { ComponentProps } from "react";

function ProfileCard({ user, ...rest }: { user?: User } & ComponentProps<"div">) {
  return (
    <div {...rest}>
      <img src={user?.avatar} width={80} height={80} alt="" />
      <h3>{user?.name}</h3>
      <p data-bones-lines="3">{user?.bio}</p>
    </div>
  );
}
```

`data-bones-lines="3"` tells the stylesheet the bio is three lines tall while it is empty.

## Add a Suspense boundary

The fallback is the same component with `aria-busy="true"` and no data:

```tsx
import { Suspense } from "react";

async function Profile() {
  const user = await fetchUser();
  return <ProfileCard user={user} />;
}

export default function Page() {
  return (
    <Suspense fallback={<ProfileCard aria-busy="true" />}>
      <Profile />
    </Suspense>
  );
}
```

There is no separate skeleton component to keep in sync. The fallback is the component. The async child is what suspends; the page itself returns at once so the fallback paints.

## Lists

A list with no data renders no rows. Give it a placeholder count:

```tsx
function PostList({ user }: { user?: User }) {
  return (
    <ul>
      {(user?.posts ?? Array.from({ length: 5 })).map((post, i) => (
        <li key={post?.id ?? i}>{post?.title}</li>
      ))}
    </ul>
  );
}
```

## Adjust a bone

Inference gets most markup right. When it does not, say what you want:

- `data-bones-type="block"` on a `div` that should paint as one box, such as an avatar with a background image.
- `data-bones-auto="off"` on a label that should stay readable while the value next to it loads.

See [Attributes](/api/attributes) for the full list.

## Keep a skeleton out of the tab order

A fallback that renders links or buttons is still focusable. Add `inert` next to `aria-busy`:

```tsx
<Suspense fallback={<ProfileCard aria-busy="true" inert />}>
```

## Requests you run yourself

Suspense and streaming paint the skeleton first, so it never flashes. A skeleton you toggle around a `fetch` can: a cached response lands in 20 ms and the bones blink. [Delay and hold](/examples#delay-and-hold) is a short function that waits before showing bones and keeps them long enough once shown.
