---
title: forceBones
description: Sentinel value for forcing skeleton mode on individual components.
---

```tsx
import { forceBones } from "@camp.dev/bones/react";
```

`forceBones` is a frozen empty object typed as `Promise<never>`. Pass it in place of a data promise to render a component's skeleton state — in a Suspense fallback, a Storybook story, or a test.

## Usage

```tsx
import { createBones, forceBones } from "@camp.dev/bones/react";

function UserCard({ user }: { user: Promise<User> }) {
  const { bone, data } = createBones(user);
  return (
    <div>
      <h2 {...bone("text", { length: 12 })}>{data?.name}</h2>
    </div>
  );
}

// Force skeleton mode for a single component:
<UserCard user={forceBones} />;
```

## Suspense fallbacks

The fallback is the same component with `forceBones` where the pending prop goes. It renders `data-bone` markup that the stylesheet styles — no client JavaScript involved:

```tsx
<Suspense fallback={<UserCard user={forceBones} />}>
  <UserCard user={fetchUser()} />
</Suspense>
```

## How it works

`createBones` checks for `forceBones` by identity (`===`). When matched, it sets `isLoading = true` and `data = undefined` without throwing a promise.

Typed as `Promise<never>` so it's assignable to any `Promise<T>` prop.

## When to use

- Preview a skeleton without real data.
- Build a Suspense fallback from the real component.
- Force a subtree by passing `forceBones` to each component in it. For unmarked content, use [`<bones-boundary force>`](/api/bones-boundary) instead.
