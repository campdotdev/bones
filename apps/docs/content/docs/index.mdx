Set `aria-busy="true"` on a region and its content becomes a skeleton. No skeleton components, no placeholder markup, no JavaScript. The stylesheet infers a text bar for every leaf and a box for every image or control, and a handful of `data-bones-*` attributes adjust the result when inference gets something wrong.

```html
<section aria-busy="true">
  <img src="/avatar.png" width="64" height="64" alt="" />
  <h2>Sasha Greenfield</h2>
  <p>Collects tape loops, birdsong, and the hum of old refrigerators.</p>
</section>
```

## The problem with skeleton components

Every async component tends to grow a matching skeleton component. The two look alike but share no code, so they fall out of sync. Add a field, update both. Rename a class, both. A dashboard with three async components means three copies of the UI that contribute nothing except loading state.

## One component, both states

Write the component so it renders its shell with no data, and forward its props to the root. The skeleton is then the component with `aria-busy` and nothing else, in a Suspense fallback, a Storybook story, or a visual test.

```tsx title="PokemonCard.tsx"
function PokemonCard({ pokemon, ...rest }: { pokemon?: Pokemon } & ComponentProps<"div">) {
  return (
    <div className="card" {...rest}>
      <img
        className="card-image"
        src={pokemon?.sprite}
        alt={pokemon?.name ?? "Pokemon"}
        width={120}
        height={120}
      />
      <h3 className="card-name">{pokemon?.name}</h3>
      <div className="card-types">
        {(pokemon?.types ?? Array.from({ length: 2 })).map((type, i) => (
          <span key={type ?? i} className="badge">
            {type}
          </span>
        ))}
      </div>
    </div>
  );
}

async function Card() {
  return <PokemonCard pokemon={await fetchPokemon()} />;
}

<Suspense fallback={<PokemonCard aria-busy="true" />}>
  <Card />
</Suspense>;
```

## Key ideas

- The stylesheet is the API. Attributes are inert until a region is busy, so you annotate real markup once.
- Works in any stack: server-rendered HTML, React Server Components, htmx, Turbo, a plain `fetch`.
- No JavaScript ships. Timing for a request you run yourself and a swap script for a bare streaming server are short recipes in these docs, not exports.
- Bones derive their color from the text color, so they contrast on any background.

## Nested and independent loading

Every component inside one `<Suspense>` boundary shows bones until the slowest promise resolves. For independent loading, give each its own boundary:

```tsx
async function User() {
  return <UserCard user={await fetchUser()} />;
}
async function StatsSection() {
  return <Stats stats={await fetchStats()} />;
}
async function Feed() {
  return <ActivityFeed feed={await fetchFeed()} />;
}

function Dashboard() {
  return (
    <>
      <Suspense fallback={<UserCard aria-busy="true" />}>
        <User />
      </Suspense>
      <Suspense fallback={<Stats aria-busy="true" />}>
        <StatsSection />
      </Suspense>
      <Suspense fallback={<ActivityFeed aria-busy="true" />}>
        <Feed />
      </Suspense>
    </>
  );
}
```

Each async child suspends its own boundary, so the three fetches run at once and each section swaps in as its data lands.
