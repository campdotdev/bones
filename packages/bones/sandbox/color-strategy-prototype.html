PROTOTYPE — bone color strategies (BON-13)

Rows are page contexts, columns are color strategies. Every bone below is the real bones.css rendering — only --bone-base / --bone-highlight differ per column. The BON-13 bug is column A after clicking the toggle: the light-page rows go blank.

Context A · published (scheme query) B · currentColor 12% C · mid-gray 25% D · dark gray 50%

Findings so far: the issue's literal option 1 fails everywhere, because bones.css hides every bone's content with color: transparent — currentColor is transparent at the bone itself, not just on images. Column B instead zeroes only the alpha (color: rgb(from currentColor r g b / 0)) so the mix can restore the channels. Cost: bones take the inherited color, so per-element tints (link blue, error red) fall back to the parent's color.
